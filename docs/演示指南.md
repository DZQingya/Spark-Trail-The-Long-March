# 课堂演示指南

## 1. 启动

启动游戏：

```text
长征·星火征途.lnk
```

也可以直接打开 `web\index.html`。如果浏览器限制本地文件，可执行：

```powershell
cd web
python -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/`。

演示前建议在标题页填写固定种子 `42`。

## 2. 3-5 分钟讲解流程

### 0:00-0:35 主题与定位

- 作品主题是纪念红军长征胜利 90 周年。
- 玩家带领的是一支红军队伍，不是单个英雄。
- 游戏重点是路线、资源、组织与历史理解，而不是无意义刷怪。

### 0:35-1:20 展示队伍与路线

- 展示侦察连、工兵连、卫生队的不同被动。
- 选择侦察连。
- 在两条路线中说明敌军数量、补给、恢复和经验收益的差异。
- 强调随机路线与每局重新开始形成 Roguelike 结构。

### 1:20-2:40 展示战斗

展示：

- 敌人下一次行动意图。
- 单击左键普通攻击，长按左键蓄力后松开发动突刺。
- 敌方蓄力重击与玩家格挡/拼刀。
- 观察敌军抬手、武器放大和刀尖闪光，在刀锋接触前按按 F 键格挡/拼刀。
- 攻击刀光、粒子、伤害数字和震屏。
- 击败敌人后进入三选一成长。

讲解：战斗是抽象的战术处置，不是把历史人物做成可随意操控的英雄。

### 2:40-3:30 展示历史节点

每章结束展示一张历史卡，包括时间、地点、史实概述、历史意义和可点击来源。推荐展示遵义会议或四渡赤水。

强调：随机战斗是玩法情景，历史节点单独核验来源。

### 3:30-4:20 展示连续成长与最终 Boss

- 12 场普通战斗后获得 12 次强化。
- 每场普通战使用单个高耐久敌人，约 5-8 次有效行动；动作衔接较快，但单场战斗不短。
- 等级、攻击、生命、暴击和补给持续成长。
- 最终 Boss“最后的封锁线”是玩法虚构的综合考验，不对应具体历史人物或战例。
- 击败 Boss 后进入会宁会师胜利页。

### 4:20-5:00 技术与课程关联

- 原生 JavaScript + HTML5 Canvas + CSS，无外部素材和第三方运行时依赖。
- Web Audio 实时生成音效。
- 历史来源覆盖中央党史和文献研究院、共产党员网、军事博物馆、求是网。
- 开发记录、测试记录和 AI 使用说明随包提交。

## 3. 答辩要点

1. 为什么选择网页 Canvas？
   画面表现和迭代效率高，课堂电脑无需安装额外运行库。

2. 如何保证历史准确性？
   历史节点独立建卡并保存来源，随机战斗明确标为玩法情景。

3. Roguelike 感来自哪里？
   随机路线、随机敌人、敌人意图、战后三选一、本局成长和失败重开。

4. 如何避免娱乐化过度？
   不设置刷怪掉落、击杀积分和真实历史人物战斗卡；Boss 明确为虚构综合封锁线。

5. AI 用在哪里？
   辅助代码、界面原型、文本草案和测试建议；历史来源、试玩修改和最终提交由本人负责。
