## 1. 创作思路

本作品不把长征做成“个人英雄刷怪升级”的动作游戏，而是让玩家带领一支红军队伍，在信息不完整、补给紧张、自然环境恶劣和敌军围追堵截的条件下作出连续判断。玩家需要选择行军路线、分配补给、利用敌人行动意图，并在每场战斗后进行成长取舍。

游戏采用 Roguelike 的随机路线、随机敌人、战斗成长、每局重开和随机种子复盘。遵义会议、四渡赤水、巧渡金沙江、强渡大渡河与飞夺泸定桥、翻越夹金山、穿越松潘草地、会宁会师等历史大节点保持固定顺序。随机性只作用于沿途战斗与风险，不改变历史主线。

## 2. 玩法结构

一局由以下内容组成：

1. 从侦察连、工兵连、卫生队中选择一种开局队伍。
2. 经过 6 个历史章节。
3. 每章进行 2 场随机路线战斗，共 12 场；每场开始前在两种路线中作出选择。
4. 每章结束进入 1 张经核验的历史节点卡。
5. 每场战斗后从 3 项强化中选择 1 项，等级与属性持续成长。
6. 最终突破“最后的封锁线”Boss，进入会宁会师胜利结局。

路线会改变敌人数量、敌军状态、战前恢复、补给和经验收益。敌军会在卡片和战场下方显示下一步意图，例如普通突击、蓄力重击、就地戒备或 Boss 的全线合围。玩家可以点击敌军切换目标。

## 3. 战斗系统

战斗操作收束为两个鼠标按键：

- **单击左键**：发动普通攻击，有明显前摇、命中与后摇。
- **长按左键后松开**：消耗 3 点补给发动蓄力突刺，前摇更长、伤害更高。
- **F 键**：敌军武器落下时格挡或拼刀。

普通攻击的总动作约 0.75 秒，突刺约 1.1 秒；动作期间不能连续出刀。敌军出手时会放大并突出抬手与武器动作，玩家观察刀尖闪光和武器下落，再按右键判断格挡时机。普通战放置单个高耐久敌人，平均需要 5-8 次行动。

不同队伍具有不同被动：

- 侦察连：首次攻击更强，暴击率高。
- 工兵连：每次受击额外减伤，格挡成功时恢复少量兵力。
- 卫生队：格挡成功时恢复兵力，战后整补效果更强。

战斗成长包括等级提升和战后三选一强化，例如攻击、生命上限、暴击、补给效率、低血量伤害和开局必暴击。Boss 在低于半血后进入更危险的第二阶段。

## 4. 资源与胜负

- 兵力：队伍的核心生存资源，归零则本局失败。
- 士气：影响伤害输出，也会被 Boss 的合围行动削弱。
- 补给：长按突刺会消耗补给；战斗结束后会补充少量补给。
- 等级与强化：代表本局内的持续成长，不跨局继承。

攻击、受击、暴击、治疗、刀光、粒子、屏幕震动和伤害数字均由 Canvas 绘制。音效由 Web Audio 实时生成，不依赖外部音频文件。

## 5. 历史与思政关联

游戏内每个章节结束显示历史节点卡，包含时间、地点、经核验概述、历史意义和来源链接。主要来源包括：

- 中共中央党史和文献研究院：遵义会议、四渡赤水、会宁会师。
- 共产党员网：长征节点综述与长征精神解读。
- 中国人民革命军事博物馆：纪念红军长征胜利 90 周年主题展览。
- 求是网：纪念红军长征胜利 90 周年专题。

历史节点坚持以下边界：

- 不编造没有来源的伤亡数字、人物对话或心理活动。
- 强渡大渡河与飞夺泸定桥分别表述，不混为同一场战斗。
- 会宁会师与将台堡、兴隆镇会师分别表述。
- 随机敌人和“最后的封锁线”Boss 是玩法情景，不对应具体历史人物或具体战例。

课程关联体现在：

1. 用资源压力和连续决策表现长征的艰难，而不是用刷怪掉落消解历史。
2. 用侦察、救护、群众带路、工程渡河等机制表现集体主义、纪律、军民关系和实事求是。
3. 用历史卡把游戏体验与史实学习连接起来。
4. 用失败与胜利复盘引导玩家理解选择、责任和代价。

详细来源见 `docs/历史资料来源.md`。

## 6. 技术实现

- JavaScript（原生，无第三方运行时依赖）
- HTML5 Canvas 战斗场景与粒子效果
- CSS 响应式 UI
- Web Audio 生成音效
- 随机种子复现随机路线、敌人和强化

启动游戏：

```text
长征·星火征途.lnk
```

也可以直接打开 `web\index.html`，或使用本地 HTTP 服务。
