# 技术方案

## 运行结构

- 前端：原生 JavaScript、HTML、CSS、Canvas。
- 启动与存档：本地 `LongMarchServer.exe` 提供静态资源与独立存档 API。
- 游戏无需安装额外运行库，浏览器负责渲染与音频输出。
- 安装版由无窗口启动器打开本地服务，不显示控制台窗口。

## 核心模块

- `web/game.js`：战斗状态机、输入、敌人 AI、地图、成长、事件、存档、设置与渲染。
- `web/style.css`：响应式界面、信物栏、设置、图鉴、战斗 HUD 和地图样式。
- `web/assets/`：音效、事件背景、主视觉与图标资源。
- `tools/LongMarchServer.cs`：静态文件服务、分块存档、战史、设置和窗口启动控制。

## 数据隔离

- 每个存档使用 `saves/<存档名_存档ID>/` 独立目录。
- 每个目录包含：
  - `meta.json`：存档名称、更新时间、教程状态。
  - `run.json`：当前局进度与战斗快照。
  - `history.json`：该存档独立的战史。
- `library.json` 只保存存档索引。
- `settings.json` 保存全局窗口与音频设置。
- 删除游戏不会删除存档根目录。

## 战斗

- 实时状态机处理前摇、判定、后摇、连段、格挡、完美格挡、闪避、识破、射击、跳跃和处决。
- 敌人使用独立招式池、节奏、位移和威胁度控制。
- Canvas 绘制人物、刀光、弹道、粒子、架势条和背景缓存。
- 地图和战斗画布按总像素预算封顶，避免高 DPR 屏幕每帧填充数百万像素；地图静态地形在普通与性能模式下都复用视口缓存。
- 性能模式限制粒子、阴影和装饰细节，并按 30/20/15/10 帧自动选择稳定档位，持续掉帧时优先降低目标帧率而不是让帧间隔忽快忽慢。
- 战斗专注与完美格挡的全屏径向渐变按强度档位缓存，画布尺寸变化时自动清空失效缓存。

## 图鉴与设置

- 图鉴分为敌情、军备、信物、战法，并可查看完整效果。
- 设置支持总音量、背景音乐、战斗音效、启动窗口、启动全屏、当前全屏、渲染清晰度和按键绑定。
- 启动窗口尺寸和启动全屏写入 `settings.json`，由启动服务在下次打开时读取。

## 测试

- `node --check web/game.js`
- Playwright 冒烟测试：界面、图鉴、设置、存档切换、战史隔离、输入和响应式布局。
- 安装包测试：静默安装、快捷方式、无窗口启动、启动最大化、卸载保留存档。
