# 长征·星火征途

红军长征主题单机动作 Roguelike 游戏。

当前版本：v0.29.6

## 启动

双击桌面或开始菜单中的“长征·星火征途”。

- 不显示黑色控制台窗口。
- 默认按设置中的启动窗口大小打开；默认最大化。
- 可在设置中指定启动窗口尺寸，或开启启动全屏。
- 安装完成后询问是否直接启动游戏；若原安装目录无写入权限，安装器会自动切换到同一用户下的可写目录。

## 操作

- WASD / 左摇杆：移动
- 左键 / J / RB：攻击，长按发动突刺
- F / LB：格挡与弹反
- Shift / B：闪避，无方向输入时后撤
- Space / A：跳跃
- R / Y：射击
- X：处决
- Q：急救
- G / 十字键上：使用小道具
- E / X：地图互动

所有按键均可在设置中重新绑定。

## 当前内容

- 即时攻防、完美格挡、拼刀、闪避反击、守势反击、识破、跳跃与处决
- 多段精英与首领战，敌人拥有独立招式、位移、快慢刀和连段
- 三幕远征模式与单幕山河探索模式
- 四层地图、自由移动、隐藏区域、机关、暗渠、NPC、任务与宝箱
- 信物、军备、技能树、军功、商店、消耗品与局内成长
- 图鉴分类：敌情、军备、信物、战法，均可查看完整详情
- 每份存档拥有独立战史
- 总音量、背景音乐、战斗音效分别调节
- 无控制台启动、后台存档服务常驻、启动窗口与全屏设置
- 暂停菜单可直接放弃本局，经确认后清除进度并记入当前存档战史
- 模式选择中普通模式位于中央主位，使用金红主题强化展示，和肉鸽模式并列成为主推玩法
- 三幕远征增加“经典肉鸽”角标，与普通模式的“主线远征 · 推荐”角标形成并列主推展示

## 存档

存档位于：

```text
%USERPROFILE%\Documents\长征·星火征途存档
```

`saves` 下每个子文件夹是一份独立存档，包含当前进度、战史和该存档的独立设置记录。复制整个子文件夹即可备份。

删除游戏本体或卸载游戏不会删除存档目录。

## 设置

设置界面支持：

- 性能模式
- 启动窗口大小
- 启动全屏
- 当前窗口立即全屏
- 总音量
- 背景音乐音量
- 战斗音效音量
- 渲染清晰度
- 手柄布局与完整按键绑定

## 卸载

双击桌面“卸载长征·星火征途”，或通过 Windows 设置 → 应用卸载。存档目录会保留。
